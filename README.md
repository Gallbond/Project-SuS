# Project Sus

Сервис для чтения текстов на польском с переводом и озвучкой любого слова по клику.

Тексты — обычные `.md`-файлы в папке `texts/`. Перевод — на русский, всегда.

## Что нужно

- Node.js 20+ (проверено на 24)
- Браузер: Chrome или Edge
- Для озвучки — польский голос в системе (см. ниже)

## Запуск

```bash
npm install
npm run dev
```

Открыть <http://localhost:5173>.

`npm run dev` поднимает две вещи сразу:

- **клиент** — Vite на `http://localhost:5173`;
- **сервер** — Express на `http://localhost:3001`, Vite проксирует на него `/api`.

## Как добавить текст

Три способа, все ведут в одну папку `texts/`:

1. Кнопка **«+ Добавить текст»** → перетащить `.md`-файл.
2. Кнопка **«+ Добавить текст»** → вкладка «Вставить текст».
3. Просто положить `.md` в папку `texts/` и обновить страницу.

Формат файла:

```md
---
title: "Название"
language: pl
level: A2
tags: [тег]
created: 2026-10-23
---

# Заголовок

Текст на польском.
```

Всё, кроме самого текста, необязательно: без `title` возьмётся первый заголовок `#`, без `language` — `pl`.

## Как это работает

- Клик по слову → карточка с переводом, транскрипцией и кнопкой ▶.
- Транскрипция (IPA) приходит из Викисловаря и кэшируется; если слова там нет — просто не показывается.
- Перевод берётся из своей правки, потом из кэша, потом из MyMemory.
- Кривой перевод можно исправить кнопкой «Исправить» — правка сохраняется навсегда.
- Кнопка «＋ В словарь» сохраняет слово с переводом и транскрипцией. Словарь открывается из шапки главной или круглой кнопкой в правом нижнем углу читалки.
- Кэш и правки лежат в `server/data/` (`cache.json`, `overrides.json`), в git не попадают.
- Наружу уходит только нажатое слово. Тексты остаются на диске.

### Качество перевода

MyMemory переводит одиночные слова, и с польскими словоформами ошибается: `książka` → «книга», а `książki` может выдать мусор. Поэтому в приложении есть ручные правки — это штатный способ добиться точности. В планах — провайдер, который видит всё предложение.

### Лимит переводчика

Бесплатно MyMemory даёт 5 000 знаков в день. Если указать email, лимит вырастет до 50 000:

```powershell
$env:MYMEMORY_EMAIL = 'you@example.com'
npm run dev
```

При исчерпании лимита приложение не падает: кэш и свои переводы продолжают работать.

## Озвучка

Используется Web Speech API и системный польский голос.

- **Windows 11:** Параметры → Время и язык → Язык и регион → Добавить язык → Polski. Галочка «Речевые пакеты».
- **Chrome/Edge:** голоса подхватываются из системы автоматически.

Если польского голоса нет, кнопка «Послушать» неактивна — это нормально, остальное работает.

## Структура

```
texts/                 твои тексты (.md)
client/                React + Vite + TypeScript
  src/pages            главная и читалка
  src/components       карточка слова, диалоги, markdown
  src/lib              api, настройки, озвучка
server/                Express + TypeScript
  src/storage.ts       чтение/запись .md
  src/dictionary.ts    личный словарь слов
  src/translate/       провайдеры перевода
  data/                кэш, правки, IPA, словарь (не в git)
SPEC.md                техническое задание
```

## Скрипты

| Команда | Что делает |
|---|---|
| `npm run dev` | клиент + сервер для разработки |
| `npm run build` | сборка клиента в `client/dist` |
| `npm start` | сервер отдаёт собранный клиент и API на `:3001` (сначала `npm run build`) |
| `npm run typecheck` | проверка типов в обоих пакетах |

## Свой язык

Язык — свойство текста (`language` в frontmatter). В коде нет константы «польский», кроме выбора голоса для озвучки: он берётся из `language` текста. Чтобы добавить язык в список при загрузке, дополните `LANGUAGES` в `client/src/components/AddTextDialog.tsx`.
